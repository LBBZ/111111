# 任务输出目录说明（task/）

本目录为每次运行评测/任务流程的统一输出汇总区。下列文件和子目录含义如下：

## 1. console.log
- 本次所有任务的详细控制台日志（含关键步骤、流程信息、部分异常），每次运行会覆盖写入。
- 便于回溯整体流程、排查问题。

## 2. error.log
- 本次所有任务的错误日志（仅包含异常、失败、警告等），每次运行会覆盖写入。
- 便于快速定位失败原因。

## 3. <任务ID>/  子目录
- 每个任务（如 1、2、3...）单独输出的详细结果目录。
- 典型内容：
  - traj.csv：无人机轨迹点（每步的x/y/z）
  - plan.json：每步决策与动作明细
  - results.json：评测指标（SR/NE/SPL等）与任务总结
  - meta.json：任务元信息（起点、指令、时间戳等）
  - lifecycle.jsonl：任务生命周期阶段日志
  - step_visual/：每步采集的图像与深度图（如有）

## 4. bootstrap/  子目录
- 启动/热身任务的输出（如有），结构同上。

## 5. workflow_summary.json
- 本次工作流汇总（bootstrap状态、每个任务成功/失败、关键指标和输出目录）。

---

- 所有日志和结果均为本次程序运行的汇总，便于整体复盘和问题定位。
- 若需历史记录，请手动备份本目录。
- 详细日志格式和内容可根据实际需求调整。

如有疑问可随时联系开发者。
